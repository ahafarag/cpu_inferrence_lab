# content/

Drafts of public write-ups generated from real results only. One file per post/article, named `YYYY-MM-DD-channel-topic.md`.

Rules:
- Every number must trace to a row in `benchmarks/results.csv`.
- Lead with the number, not the story.
- Negative results are posted too. "PowerInfer did not build on WSL after 2 hours; here is why" is a valid post.
- Channels: LinkedIn (primary), r/LocalLLaMA, Hacker News (only for a finished tool), short video via the owner's reels pipeline.
