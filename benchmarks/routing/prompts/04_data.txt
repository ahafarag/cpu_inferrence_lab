I have a table called orders with columns order_id, customer_id, created_at, status, and total_amount, and a table called customers with columns customer_id, country, and signup_date. Write a SQL query for PostgreSQL that returns, for each country, the number of customers who placed at least one completed order in the last 90 days, the total revenue from those orders, and the average order value, sorted by revenue descending and limited to the top ten countries. Then explain which indexes you would add to make the query fast on a table with fifty million rows, and describe how you would detect that the query planner is choosing a sequential scan by mistake. Also point out one subtle bug that appears if the status column contains values in mixed case such as Completed and completed.
